📄 HTML (HyperText Markup Language)

HTML is the standard markup language for creating web pages. It provides the structure and content of a website.

Key Elements:

  • <!DOCTYPE html> - Declares the document type
  • <html> - Root element
  • <head> - Contains metadata
  • <body> - Contains page content
  • <div> - Container for grouping elements
  • <p> - Paragraph
  • <h1> to <h6> - Headings
<!DOCTYPE html>
<html>
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Welcome!</h1>
    <p>This is a paragraph.</p>
  </body>
</html>

🎨 CSS (Cascading Style Sheets)

CSS is used to style and layout web pages — for example, to alter the font, color, size, and spacing of your content.

Key Concepts:

  • Selectors - Target HTML elements
  • Properties - Define what to style
  • Values - Specify how to style
  • Box Model - Margin, border, padding, content
  • Flexbox - Flexible layouts
  • Grid - Advanced layouts
/* Selector with properties */
body {
  font-family: Arial, sans-serif;
  background-color: #f0f0f0;
  margin: 0;
  padding: 20px;
}

.container {
  max-width: 800px;
  margin: 0 auto;
  background: white;
  border-radius: 8px;
}

h1 {
  color: #667eea;
  font-size: 32px;
}

⚙️ JavaScript

JavaScript is a programming language that enables interactive web pages and is an essential part of web applications.

Key Features:

  • Variables - Store data
  • Functions - Reusable code blocks
  • Events - Respond to user actions
  • DOM Manipulation - Change HTML content
  • Loops & Conditionals - Control flow
  • Objects & Arrays - Data structures
// Function example
function openTab(evt, tabName) {
  // Hide all content
  let content = document.querySelectorAll('.tab-content');
  content.forEach(el => el.classList.remove('active'));
  
  // Show selected tab
  document.getElementById(tabName).classList.add('active');
  
  // Highlight active button
  let buttons = document.querySelectorAll('.tab-button');
  buttons.forEach(btn => btn.classList.remove('active'));
  evt.currentTarget.classList.add('active');
}

// Event listener
document.addEventListener('click', function(event) {
  console.log('Page clicked!');
});
